# HostRifa Backend

Um sistema agregador de rifas, onde os usuários podem encontrar, criar e participar dos mais diversos tipos de rifas.

## Funcionalidades

- [ ] Cadastro de usuarios (Em desenvolvimento)
- [ ] Login
- [ ] Criar rifas
- [ ] Participar das rifas
- [ ] Fazer Pagamento


## Tecnologias utilizadas

- NodeJs
- JavaScript
- MySql
- Express(framework)
- Nodemon ( auto reload - apenas no modo desenvolvimento)
